# Image Replacer — data

Публичный источник данных для плагина Image Replacer.

## Структура

- `people/` — изображения пользователей.
- `company/` — изображения компаний.
- `public/` — изображения пабликов.
- `links.json` — связи между ключами данных, именами и изображениями.
- `edit.json` — имена слоёв, в которых плагин обновляет имя и должность.
- `version.json` — версия и дата обновления набора данных.

## Как обновлять данные

1. Добавьте или замените изображения в соответствующей папке.
2. Обновите записи в `links.json`.
3. При необходимости измените `edit.json`.
4. Обновите `version.json` и отправьте изменения в репозиторий.

Не размещайте здесь реальные персональные данные, секреты, токены или закрытые материалы.
